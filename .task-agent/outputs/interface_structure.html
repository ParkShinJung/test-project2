2. User 모듈 인터페이스 상세

📋 IUser (기본 엔티티)

interface IUser { id: string; // 사용자 고유 ID name: string; // 사용자 이름 email: string; // 사용자 이메일 phone?: string; // 사용자 전화번호 (선택) address?: string; // 사용자 주소 (선택) createdAt: Date; // 생성 날짜 updatedAt: Date; // 수정 날짜 isActive: boolean; // 활성화 여부 }

📋 ICreateUserRequest (생성 요청)

interface ICreateUserRequest { name: string; email: string; phone?: string; address?: string; }

📋 IUpdateUserRequest (수정 요청)

interface IUpdateUserRequest { name?: string; email?: string; phone?: string; address?: string; isActive?: boolean; }

📋 User 관련 타입

UserRole: 'admin' | 'user' | 'guest'
UserStatus: 'active' | 'inactive' | 'suspended' | 'deleted'
UserGender: 'male' | 'female' | 'other' | 'not_specified'
UserSortBy: 'id' | 'name' | 'email' | 'createdAt' | 'updatedAt'
3. Post 모듈 인터페이스 상세

📋 IPost (기본 엔티티)

interface IPost { id: string; // 게시글 고유 ID title: string; // 게시글 제목 content: string; // 게시글 내용 authorId: string; // 작성자 ID (FK) author?: IUser; // 작성자 정보 (선택) category?: string; // 카테고리 tags?: string[]; // 태그 목록 viewCount: number; // 조회수 likeCount: number; // 좋아요 수 commentCount: number; // 댓글 수 createdAt: Date; // 생성 날짜 updatedAt: Date; // 수정 날짜 deletedAt?: Date; // 삭제 날짜 (소프트 삭제) isPublished: boolean; // 공개 여부 isPinned: boolean; // 고정 여부 }

📋 ICreatePostRequest (생성 요청)

interface ICreatePostRequest { title: string; content: string; authorId: string; category?: string; tags?: string[]; isPublished?: boolean; }

📋 IUpdatePostRequest (수정 요청)

interface IUpdatePostRequest { title?: string; content?: string; category?: string; tags?: string[]; isPublished?: boolean; isPinned?: boolean; }

📋 Post 관련 타입

PostStatus: 'draft' | 'published' | 'archived' | 'deleted'
PostCategory: 'notice' | 'general' | 'question' | 'review' | 'free' | 'other'
PostSortBy: 'id' | 'title' | 'createdAt' | 'updatedAt' | 'viewCount' | 'likeCount' | 'commentCount'
PostFilterOptions: category, authorId, isPublished, isPinned, tags, createdAfter, createdBefore, minViewCount, minLikeCount, searchKeyword
PostSearchOptions: keyword, searchIn, category, authorId
4. 응답 인터페이스

📋 IUserResponse & IUserListResponse

interface IUserResponse { success: boolean; data?: IUser; message?: string; error?: string; } interface IUserListResponse { success: boolean; data?: IUser[]; total?: number; message?: string; error?: string; }

📋 IPostResponse & IPostListResponse

interface IPostResponse { success: boolean; data?: IPost; message?: string; error?: string; } interface IPostListResponse { success: boolean; data?: IPost[]; total?: number; page?: number; limit?: number; message?: string; error?: string; }

📋 IPostStatistics

interface IPostStatistics { totalPosts: number; totalViews: number; totalLikes: number; averageComments: number; postsPerCategory: Record<string, number>; }
5. 관계 및 의존성

🔗 User-Post 관계

관계 유형: One-to-Many (1:N)
외래키: Post.authorId → User.id
카디널리티: User (1) : Post (0..*)
설명: 한 명의 사용자는 여러 개의 게시글을 작성할 수 있습니다.

📦 모듈 의존성

Post 모듈: User 인터페이스에 의존 (IUser 타입 참조)
User 모듈: 독립적 (다른 모듈에 의존하지 않음)
공통 의존: 공통 타입, 데코레이터, 필터, 인터셉터
